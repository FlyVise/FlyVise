# FLYVISE — Design. Develop. Dominate.

A 360° marketing agency website built with pure HTML, CSS, and vanilla JavaScript.

## 📁 File Structure

```
flyvise/
├── index.html              # Main HTML — all page sections & overlays
├── assets/
│   ├── css/
│   │   └── style.css       # All styles — global, components, overlays, responsive
│   └── js/
│       └── main.js         # Custom cursor, scroll reveal, service accordions, overlays
└── README.md
```

## 🚀 Deploy to GitHub Pages

1. Push this folder to a GitHub repository
2. Go to **Settings → Pages**
3. Source: **Deploy from branch** → `main` → `/ (root)`
4. Your site will be live at: `https://yourusername.github.io/flyvise`

## 🎨 Tech Stack

- **HTML5** — Semantic, accessible markup
- **CSS3** — Custom properties, Grid, Flexbox, animations
- **Vanilla JS** — No frameworks, no dependencies
- **Fonts** — Bebas Neue, Syne, DM Sans (Google Fonts)
